# 启动与界面整理

按用户本轮范围完成，不新增同步能力，不改变远端上报协议或账本归属规则。

- 根目录 `start.cmd` 使用已有虚拟环境；可双击或从任意目录调用，服务就绪后打开浏览器。
  同项目同账号服务已运行时复用现有进程，端口冲突则说明原因，不结束其他进程。
  启动窗口内 Ctrl+C 停止本次启动的服务。支持 `--no-browser`、`--port` 和只读 `--check`。
- 两个授权入口移至右上角，分别打开原生模态弹窗；支持关闭按钮、Escape 和点击遮罩关闭。
- 移除大标题与宣传段落，缩小顶部留白、按钮及表单尺寸。
- 搜索区默认折叠，紧凑输入框；搜索返回时展开结果。缺 Key 时自动打开对应授权弹窗。
- 账本默认仅展示列表；点击行或书名显示对应流程并高亮该行，同时只显示一个条目。
  再点该行或“收起流程”即可收起。键盘可使用书名链接。
  任务结果的深链接会展开相应条目和高级操作，表单返回后保持对应条目选择。
- 新增本地静态 JS 仅处理展示，不发请求或自动启动阅读；CSP 仅允许同源脚本。
